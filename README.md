# Forage's Programs

> Projetos guiados focados em Dados na plataforma Forage.

## Sobre o projeto

Este projeto tem como objetivo **Melhorar habilidades em python** utilizando análise de dados.

A proposta é transformar dados em informações úteis para apoiar decisões relacionadas a Mercados, Bancos e empresas no geral.

## Objetivos

- Investigar comportamento de clientes/consumidores.
- Identificar padrões, tendências ou anomalias.
- Aplicar técnicas de análise de dados para gerar insights.
- Propor recomendações fundamentadas nos resultados.

## Tecnologias utilizadas

- Python
- Pandas
- Power BI
- Excel



## Dados utilizados

**Fonte:** [theforage.com](https://www.theforage.com/)


**Preparação dos dados:**
- Tratamento de valores ausentes.
- Verificação de duplicatas e inconsistências.
- Transformação e criação de variáveis, quando necessário.

## Metodologia

1. **Entendimento do problema:** definição das perguntas analíticas.
2. **Análise exploratória:** investigação da distribuição e das relações entre variáveis.
3. **Tratamento dos dados:** limpeza, padronização e preparação.
4. **Análise:** aplicação das técnicas adequadas ao problema.
5. **Interpretação:** avaliação dos resultados e elaboração de recomendações.
